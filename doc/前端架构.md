# Web 前端架构（可切换地图引擎）

目标：时间轴、纪年、图例、点选、`atlasAPI` 与具体地图库解耦。换引擎时只新增/替换 `web/js/map/engines/*`，不改应用层语义。

## 分层

```text
web/
  index.html              # 壳层；#map-host 是引擎挂载点（不含引擎专有 DOM）
  css/style.css
  data/atlas.json         # 导出数据（与引擎无关）
  js/
    config.js             # MAP_ENGINE 等开关
    app.js                # 应用编排：读配置 → 建引擎 → 绑时间轴/UI/i18n
    i18n/
      index.js            # 语言解析、切换、t()、data-i18n
      messages.js         # zh / ja / en 界面文案
    core/
      chrono.js            # 公元 / 日本年号 / 中国主体纪年（随语言）
      names.js            # names 对象按语言选取
      atlas_model.js      # 阶段、争议、MapFrame
    map/
      contract.js         # MapFrame / MapSelectEvent 形状说明
      registry.js         # 引擎注册表 createMapEngine(id, host, options)
      engines/
        svg_mercator.js   # 当前默认实现（自研 SVG）
        # maplibre.js     # 未来：实现同一契约即可接入
```

## 契约（应用 → 引擎）

应用每年（或每次 `setYear`）构造一帧 `MapFrame`，调用 `engine.setFrame(frame)`。

| 字段 | 含义 |
| --- | --- |
| `year` | 当前天文/公历展示年 |
| `locale` | `zh` / `ja` / `en`，引擎标注用 |
| `coastline` | 列岛海岸 GeoJSON（可与上年相同；引擎可自行缓存） |
| `polities` | 势力面：`{ id, names, color, mode, geometry }` |
| `markers` | 点标记：`{ id, lon, lat, names, kind }` |
| `disputes` | 争议：`{ id, names, short_note, parties, geometry:{lon,lat}, ... }` |

引擎 → 应用的事件只有：

- `select`：`{ kind: "polity" \| "marker" \| "dispute", data }`

引擎必须提供：

- `mount(hostEl)` / 构造时挂载
- `setFrame(frame)`
- `fitHome()`
- `on(type, handler)`
- `destroy()`（可选但建议）

引擎**不得**依赖 `#map-svg` 等页面写死的节点；自己在 `#map-host` 内创建 DOM。

## 切换引擎步骤

1. 在 `js/map/engines/` 新增实现，导出 `createXxxEngine(host, options)`，满足上述契约。
2. 在 `js/map/registry.js` 注册 `id → factory`。
3. 改 `js/config.js` 的 `MAP_ENGINE`（或 URL `?engine=maplibre`）。
4. 不要改 `core/*` 与 `setYear` 的业务语义。

## 多语言

- UI 语言：`zh`（简体）/ `ja` / `en`，顶栏一键切换。
- 优先级：`?lang=` → `localStorage.soe.lang` → 浏览器语言 → 默认 `zh`。
- 界面文案走 `t(key)` / `data-i18n`；史实名称走 atlas 的 `names.zh_hans|ja|en`。
- API：`atlasAPI.setLang('ja')`、`atlasAPI.getLang()`。

## 当前默认

`MAP_ENGINE = "svg_mercator"`。行为与改架构前一致；性能优化与 MapLibre 接入都在引擎目录内完成。
