# Web 前端架构（可切换地图引擎）

目标：时间轴、纪年、图例、点选、`atlasAPI` 与具体地图库解耦。换引擎时只新增/替换 `web/js/map/engines/*`，不改应用层语义。

## 分层

```text
web/
  index.html              # 壳层；#map-host 是引擎挂载点（不含引擎专有 DOM）
  css/style.css
  data/atlas.json         # 导出数据（与引擎无关）
  js/
    config.js             # MAP_ENGINE 等开关
    app.js                # 应用编排：读配置 → 建引擎 → 绑时间轴/UI/i18n
    i18n/
      index.js            # 语言解析、切换、t()、data-i18n
      messages.js         # zh / ja / en 界面文案
    core/
      chrono.js            # 公元 / 日本年号 / 中国主体纪年（随语言）
      names.js            # names 对象按语言选取
      atlas_model.js      # 阶段、争议、MapFrame
    map/
      contract.js         # MapFrame / MapSelectEvent 形状说明
      registry.js         # 引擎注册表 createMapEngine(id, host, options)
      engines/
        maplibre.js       # 当前默认实现（MapLibre GL JS；CDN；示意海岸+势力 GeoJSON）
        terrain_glb_layer.js  # MapLibre Custom Layer + Three：GLB 底图
        terrain_calib.js  # 锚点仿射 / AABB↔bounds 校准
        svg_mercator.js   # 自研 SVG 墨卡托（可用 ?engine=svg_mercator）
    models/
      Japan_3D_Map.glb          # 3D 地形底图
      Japan_3D_Map.calib.json   # 锚点校准（札幌/东京/那霸等）
```

## 契约（应用 → 引擎）

应用每年（或每次 `setYear`）构造一帧 `MapFrame`，调用 `engine.setFrame(frame)`。

| 字段 | 含义 |
| --- | --- |
| `year` | 当前天文/公历展示年 |
| `locale` | `zh` / `ja` / `en`，引擎标注用 |
| `coastline` | 列岛海岸 GeoJSON（可与上年相同；引擎可自行缓存） |
| `polities` | 势力面：`{ id, names, color, mode, geometry }` |
| `markers` | 点标记：`{ id, lon, lat, names, kind }` |
| `disputes` | 争议：`{ id, names, short_note, parties, geometry:{lon,lat}, ... }` |

引擎 → 应用的事件只有：

- `select`：`{ kind: "polity" \| "marker" \| "dispute", data }`

引擎必须提供：

- `mount(hostEl)` / 构造时挂载
- `setFrame(frame)`
- `fitHome()`
- `on(type, handler)`
- `destroy()`（可选但建议）

引擎**不得**依赖 `#map-svg` 等页面写死的节点；自己在 `#map-host` 内创建 DOM。

## 切换引擎步骤

1. 在 `js/map/engines/` 新增实现，导出 `createXxxEngine(host, options)`，满足上述契约。
2. 在 `js/map/registry.js` 注册 `id → factory`。
3. 改 `js/config.js` 的 `MAP_ENGINE`（或 URL `?engine=svg_mercator` / `?engine=maplibre`）。
4. 不要改 `core/*` 与 `setYear` 的业务语义。

## 多语言

- UI 语言：`zh`（简体）/ `ja` / `en`，顶栏一键切换。
- 优先级：`?lang=` → `localStorage.soe.lang` → 浏览器语言 → 默认 `zh`。
- 界面文案走 `t(key)` / `data-i18n`；史实名称走 atlas 的 `names.zh_hans|ja|en`。
- API：`atlasAPI.setLang('ja')`、`atlasAPI.getLang()`。

## 当前默认

默认 `MAP_ENGINE = "maplibre"`：首次加载从 unpkg 拉取 MapLibre GL JS/CSS，用空白示意样式叠海岸线、势力面、标记与争议点（不依赖商业底图 key）。`maplibre` 在 style `load` 前会暂存 `setFrame`；`fitHome` 对齐日本示意范围。

默认再垫一层 GLB 地形（`TERRAIN_GLB`）：Custom Layer + Three.js 加载 `web/models/Japan_3D_Map.glb`，校准见 `Japan_3D_Map.calib.json`。模型网格近似 lon/lat 平面，运行时先锚点仿射到经纬度，再**逐顶点**烘焙进 Web Mercator（避免用单次墨卡托仿射造成南北弯曲）。GeoJSON 叠层与点选不变；地形成功后海岸填充透明。体积约 87MB，有进度条；后续可 Draco/简化。

注：库内海岸/势力面多为**示意多边形**，与精细 DEM 岸线不会逐湾吻合；投影烘焙只消除「地形相对真经纬度」的系统性错位。

| URL | 作用 |
| --- | --- |
| `?terrain=0` | 关闭 GLB 底图 |
| `?terrain_calib=1` | 点击地形 raycast 采锚点；控制台 `atlasAPI.dumpTerrainCalib()` |
| `?engine=svg_mercator` | 切回自研 SVG |

### 都道府县地名×时间

点击都道府县（填色命中层／界线／标签）→ `select.kind = prefecture` → `#place-name-panel` 展示该县 `prefecture_name_spans.json` 中的名称段。色条在统一时间轴上按 `(to-from)/(yearMax-yearMin)` 比例铺开；可跳到该段 `from_year`。

### 参勤交代试点（MapLibre）

`1635–1862` 年显示 CODH 街道底图（`edo_roads_subset.geojson`）与萨摩／加贺两条宿次折线（`sankin_routes.json`）。点选路线 → `select.kind = sankin`。数据由 `db/data/build_sankin_routes.py` 生成；示意折线，非逐里实测。

仍保留 `svg_mercator`：改 `MAP_ENGINE` 或 URL 如上。
